# Simulation study results

Generated by `python evaluation/run_simulation.py` (from `backend/`). Do not edit by hand; rerun the script instead. Raw rows: `results/simulation_results.csv`.

## Setup

- Base data: bfi complete cases on the 25 items, **2436** respondents.
- Patterns: random, straightline, patterned, midpoint, partial (definitions in `evaluation/simulate.py`).
- Contamination rates: 5%, 10%, 20% (careless respondents: 5% = 122, 10% = 244, 20% = 487).
- Repetitions: 20 per pattern and rate, seeds 0–19. Cells show the mean ± SD (ddof = 1) over repetitions.
- Scores evaluated: Composite score, Longstring, Mahalanobis D², Even-odd consistency, Psychometric synonyms, Person-total correlation.
- Not computed on this data, so not evaluated: Seconds per item.
- Psychometric synonyms was computed in 40 of 300 runs (straightline at 10%, straightline at 20%). In the other runs it could not be computed, so it is not evaluated there.

How to read the numbers:

- **ROC-AUC**: the chance that a randomly chosen careless respondent scores as more suspicious than a randomly chosen attentive one. 0.5 is chance, 1 is perfect.
- **PR-AUC** (average precision): how precise the ranking stays as more careless respondents are found. Chance level equals the contamination rate (0.05, 0.10 or 0.20), so the same PR-AUC means more at a lower rate.
- A respondent whose index could not be computed is ranked as least suspicious for that index, because the index cannot flag them. See the last table for how often this happened.

## Limitations

- The base data contains some genuinely careless respondents, labelled 0 here. Flagging them counts as a false positive, which slightly understates precision.
- Simulated patterns are cleaner than real careless responding (real respondents drift in and out of attention). These results show what the indices can detect, not how well they work on real careless respondents.
- Results are for one dataset (25 items, 6-point scale, five 5-item scales). Other surveys can give different results.
